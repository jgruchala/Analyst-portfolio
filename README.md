# Analyst-portfolio
## Product "Breed Longevity"
This file examines breed longevity prospects according to type. Types are sorted according to the 
American Kennel Club (AKC), and the raw data is from the AKC's Canine Inherited Disorders Database. 
I downloaded the data set from David McCandless at [informationisbeautiful.net](https://informationisbeautiful.net/visualizations/best-in-show-whats-the-top-data-dog/)
Each breed is sorted into either the herding breeds, terrier breeds, sporting breeds, toy breeds, 
working breeds, non-sporting breeds, or hound breeds. My approached consisted of averaging the average lifespans among breeds in each
AKC category, with the result being the average lifespand of each AKC category. I then present this data visually in a bar graph.
